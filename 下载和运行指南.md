# 如何获取和运行程序 / How to Get and Run the Program

## 方法一：直接下载编译好的程序（推荐）/ Method 1: Download Compiled Program (Recommended)

### 使用 GitHub Actions 编译的版本 / Use GitHub Actions Build

如果仓库配置了 GitHub Actions，可以从 Actions 页面下载最新的编译版本。  
If the repository has GitHub Actions configured, you can download the latest build from the Actions page.

### 本地编译 / Build Locally

由于可执行文件大小超过 GitHub 文件限制（147MB），需要自己编译：  
Since the executable size exceeds GitHub file limit (147MB), you need to build it yourself:

**简单一键编译 / Simple One-Command Build:**

```bash
# Windows PowerShell 或 命令提示符
dotnet publish LicenseGenerator.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ./output

# 编译完成后，程序位于：
# After building, the program is located at:
# output/LicenseGenerator.exe
```

**系统要求 / Requirements:**
- 安装 .NET 8.0 SDK 或更高版本
- Install .NET 8.0 SDK or higher
- 下载地址 / Download: https://dotnet.microsoft.com/download

## 方法二：直接复制源代码运行 / Method 2: Copy Source Code and Run

### 步骤 / Steps:

1. **复制所有源代码文件 / Copy all source code files:**
   - `Program.cs`

2. **创建新文件夹并保存文件 / Create new folder and save files**


3. **打开终端/命令提示符，进入文件夹 / Open terminal/command prompt, navigate to folder**
   ```bash
   cd MyLicenseGenerator
   ```

4. **运行程序（开发模式）/ Run program (Development mode)**
   ```bash
   dotnet run
   ```

   ```bash
   dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
   ```

## 常见问题 / FAQ

### Q: 为什么仓库里没有编译好的 .exe 文件？
A: 因为可执行文件大小（147MB）超过 GitHub 单文件限制（100MB），需要自己编译。编译非常简单，只需一行命令。

### Q: Why is there no compiled .exe file in the repository?
A: Because the executable file size (147MB) exceeds GitHub's single file limit (100MB), you need to build it yourself. Building is very simple, just one command.

### Q: 我没有安装 .NET SDK，能运行吗？
A: 编译需要 .NET SDK。但编译后的程序是自包含的，可以在没有 .NET 的电脑上运行。

### Q: I don't have .NET SDK installed, can I run it?
A: .NET SDK is required for building. However, the compiled program is self-contained and can run on computers without .NET.

### Q: 如何验证程序是否编译成功？
A: 编译成功后，在输出目录会看到 LicenseGenerator.exe 文件（约147MB）和一些 DLL 文件。双击运行应该能看到程序界面。

### Q: How to verify if the program compiled successfully?
A: After successful compilation, you should see LicenseGenerator.exe file (about 147MB) and some DLL files in the output directory. Double-clicking should show the program interface.
