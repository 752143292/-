# 李向前FIRE - 授权码生成器

## 项目说明 / Project Description

这是一个Windows桌面应用程序，用于根据机器码生成授权码。

This is a Windows desktop application for generating authorization codes based on machine codes.

## 功能特点 / Features

1. **标题显示** - 顶部显示"李向前FIRE"
   - Title Display - Shows "李向前FIRE" at the top

2. **时间显示** - 实时显示当前日期和时间（每秒更新）
   - Time Display - Shows current date and time in real-time (updates every second)

3. **机器码输入** - 输入12位机器码
   - Machine Code Input - Enter 12-character machine code
   - 自动转换为大写 / Automatically converts to uppercase
   - 限制12位字符 / Limited to 12 characters

4. **授权码生成** - 点击"生成授权码"按钮计算授权码
   - Authorization Code Generation - Click "Generate Authorization Code" button to calculate

5. **授权码复制** - 点击"复制授权码"按钮将授权码复制到剪贴板
   - Copy Authorization Code - Click "Copy Authorization Code" button to copy to clipboard

## 构建说明 / Build Instructions

### 开发环境要求 / Development Requirements
- .NET 8.0 SDK 或更高版本 / .NET 8.0 SDK or higher
- Windows 操作系统（用于运行） / Windows OS (for running)

### 构建项目 / Build Project
```bash
dotnet build LicenseGenerator.csproj
```

### 发布为独立EXE / Publish as Standalone EXE
```bash
dotnet publish LicenseGenerator.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

发布的EXE文件位于：`bin/Release/net8.0-windows/win-x64/publish/LicenseGenerator.exe`

Published EXE location: `bin/Release/net8.0-windows/win-x64/publish/LicenseGenerator.exe`

## 使用说明 / Usage Instructions

1. 运行 `LicenseGenerator.exe`
   - Run `LicenseGenerator.exe`

2. 在"机器码"输入框中输入12位机器码
   - Enter a 12-character machine code in the "Machine Code" input box

3. 点击"生成授权码"按钮
   - Click the "Generate Authorization Code" button

4. 授权码将显示在下方的文本框中
   - The authorization code will be displayed in the text box below

5. 点击"复制授权码"按钮将授权码复制到剪贴板
   - Click "Copy Authorization Code" to copy to clipboard
