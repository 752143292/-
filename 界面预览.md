## 特殊功能展示 / Special Features

### 自动大写转换
```
输入: abcdefghijkl    →    显示: ABCDEFGHIJKL
输入: xyz123abc456    →    显示: XYZ123ABC456
输入: AbC123DeF456    →    显示: ABC123DEF456
```

### 长度限制
```
尝试输入: ABCDEFGHIJKLMNOPQRSTUVWXYZ (26个字符)
实际接受: ABCDEFGHIJKL (只接受前12个字符)
```

### 时间自动更新
```
13:10:25  →  13:10:26  →  13:10:27  →  13:10:28  ...
(每秒自动更新，无需手动刷新)
```
